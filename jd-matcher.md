```markdown
[Hook: Business Impact]
"In my work at [Project from Matrix], I [action using resume verb] to [business purpose], which [approved impact phrase from resume]."

[Execution: Technical Detail]
"Using [SPRO path/T-code from skills.md], I [specific configuration step], and integrated with [module/system] via [integration method] to enable [outcome]."

[Proof: Challenge + Solution]
"When [challenge] arose, I [problem-solving approach from projects.md], which prevented [negative outcome] and ensured [positive result]."

[Close: JD Alignment]
"For this role at [Company], I'd apply similar approach to [JD requirement], helping you achieve [goal from JD context]."

### Example: JD Keyword = "Cold-chain compliance"
"In my work at HP Hood, I developed putaway strategies using SLED/FIFO logic for dairy products with strict expiration control, which significantly improved operator efficiency and reduced errors.

Using SPRO → SCM EWM → Master Data → Define Storage Type, I configured temperature-zone bin attributes and integrated batch determination logic to enforce FDA-compliant handling. I also collaborated with QM to embed inspection release as a POSC gate for high-risk batches.

When mixed-temperature receipts caused workflow confusion, I customized RF screen variants that guided operators through zone-specific steps, preventing misplacement and ensuring traceability.

For this role at [Company], I'd apply similar compliance-by-design thinking to your cold-storage operations, helping you achieve audit readiness while maintaining throughput."
```
